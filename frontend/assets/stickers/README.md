# Учебные стикеры

`chick-study-atlas.png` создан встроенным image_gen. Прозрачный атлас 2×2 отображается через обрезку контейнером React Native; исходный PNG не изменён.

Промпт: один оригинальный круглый жёлтый цыплёнок в четырёх учебных позах, в стиле мультяшных стикеров мессенджера: читает зелёную книгу, машет в выпускной шапочке, держит карандаш, радуется идее. Одинаковый персонаж, тёмный контур, белая окантовка, прозрачный фон, равные ячейки 2×2, без текста и водяных знаков.

В интерфейсе стикеры покачиваются и меняют позу каждые 4,2 секунды. Это анимация компонентов и смена изображений, а не покадровая анимация персонажа. Учитывается системная настройка уменьшения движения.
